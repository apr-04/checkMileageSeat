# ✈️ 대한항공 마일리지 빈좌석 모니터링 & 텔레그램 알리미

대한항공(Korean Air SKYPASS)의 마일리지 보너스 항공권(일반석, 프레스티지석, 일등석, 좌석승급)의 잔여 좌석을 자동으로 검색하고, **새로운 빈 좌석이나 취소표가 열렸을 때 텔레그램으로 즉시 알림**을 발송하는 프로그램입니다.

---

## 🌟 주요 기능

1. **🌍 어디로 갈까? 빈좌석 목적지 탐색기 (NEW!)**
   - *"이번 10월에 프레스티지석(비즈니스) 남아있는 여행지가 어디지?"*
   - 출발지와 원하는 시기(월), 좌석 등급, 지역(일본, 동남아, 유럽, 미주 등)을 고르면 **마일리지 예약이 가능한 목적지 랭킹과 날짜 목록을 일괄 탐색**하여 카드 형태로 한눈에 보여줍니다.
2. **실시간 특정 노선 보너스 좌석 고속 조회**
   - 대한항공 공식 보너스 좌석 API 연동
   - 원하는 노선(예: 인천 ➔ 나리타, 파리 등)의 한 달 치 전체 항공편 잔여 좌석을 1~2초 내에 고속 조회
3. **신규 오픈 및 취소표 자동 감지 (중복 알림 방지)**
   - 이전 검색 상태를 로컬 캐시에 기록하여 매번 같은 좌석을 스팸처럼 알리지 않고, **새로 빈자리가 생겼거나 취소표가 발생한 경우에만 똑똑하게 알림**
4. **텔레그램 실시간 알림 연동**
   - 항공편 일자, 요일, 편명, 출발 시각, 좌석 등급, 그리고 즉시 예매할 수 있는 직행 링크까지 포함된 깔끔한 알림 발송
   - 웹 화면에서 [연결 테스트 및 알림 발송] 기능 지원
5. **편리한 사용 인터페이스 (2가지 모드 제공)**
   - **웹 대시보드 (Web UI)**: 브라우저에서 마우스 클릭만으로 목적지 탐색, 노선 검색, 감시 노선 관리, 텔레그램 설정, 실시간 로그 확인 가능 (`run_web.bat`)
   - **CLI 백그라운드 서비스**: 서버나 PC 백그라운드에서 조용히 무중단으로 주기 감시 수행 (`run_monitor.bat`)

## ☁️ Git 호스팅 및 배포 방법

### 🌐 옵션 1. GitHub Pages 웹사이트 무료 배포 (인터넷에서 바로 검색!) ⭐️⭐️⭐️
내 컴퓨터를 켜지 않아도, 인터넷 브라우저(`https://<아이디>.github.io/<저장소>/`)에서 마일리지 빈 좌석을 즉시 조회하고 목적지를 탐색할 수 있습니다.

1. 이 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 **[Settings]** ➔ 좌측 메뉴 **[Pages]** 로 이동합니다.
3. **Build and deployment** 항목에서:
   - Source: **Deploy from a branch** 선택
   - Branch: **`main`** 브랜치 선택, 폴더는 **`/docs`** 선택 후 **[Save]** 클릭
4. 약 1분 후 상단에 표시되는 `https://<본인아이디>.github.io/<저장소이름>/` 링크로 접속하면 **웹사이트에서 목적지 탐색 및 빈좌석 검색 기능을 즉시 이용**하실 수 있습니다!
5. GitHub Actions가 30분마다 주요 노선 좌석 데이터를 자동 수집하여 웹사이트에 최신 상태로 갱신해 줍니다.

---

### 🔔 옵션 2. GitHub Actions 무료 24/7 텔레그램 자동 알림 (서버리스)
컴퓨터를 켜두지 않아도 **GitHub의 무료 클라우드 가상머신이 30분마다 알아서 실행**되어 대한항공 빈좌석을 감시하고 텔레그램으로 알림을 보내줍니다.

1. GitHub 저장소의 **[Settings]** ➔ **[Secrets and variables]** ➔ **[Actions]** 로 이동합니다.
2. **[New repository secret]** 버튼을 눌러 아래 2개의 시크릿을 등록합니다:
   - `TELEGRAM_BOT_TOKEN` : 발급받은 텔레그램 봇 토큰
   - `TELEGRAM_CHAT_ID` : 본인의 텔레그램 Chat ID
3. 저장소의 **[Actions]** 탭으로 이동하여 **`KAL Award Seat Monitor & Web Dataset Builder`** 워크플로우를 확인합니다.
   - 30분마다 자동으로 감시 및 웹사이트 데이터 갱신이 진행됩니다!

### 옵션 B. Docker / Docker Compose 배포 (VPS, NAS, 개인 서버)
클라우드 인스턴스(AWS, Oracle Cloud 등)나 홈서버에서 웹 대시보드를 띄우고 싶을 때:

```bash
# 3. 브라우저에서 접속

```

## 📱 텔레그램 봇 설정 1분 가이드

알림을 받으시려면 텔레그램 봇 토큰과 본인의 Chat ID가 필요합니다. (무료이며 1분이면 완료됩니다)

1. **봇 토큰(Bot Token) 발급**:
   - 텔레그램 검색창에서 **`@BotFather`** 검색 후 대화 시작
   - `/newbot` 입력
   - 봇 이름과 사용자명(끝이 `bot`으로 끝남) 입력
   - 발급되는 **HTTP API 토큰** (예: `7123456789:AAFn_XXXXXXXXXX`) 복사
2. **내 Chat ID 확인**:
   - 텔레그램 검색창에서 **`@userinfobot`** 검색 후 대화 시작
   - 봇이 알려주는 **Id 숫자** (예: `123456789`) 복사
3. **내가 만든 봇에게 말 걸기 (필수!)**:
   - 1단계에서 만든 본인 봇으로 이동하여 **[시작(Start)]** 버튼을 누르거나 `/start`를 전송합니다. (첫 대화가 있어야 봇이 나에게 메시지를 보낼 수 있습니다)
4. **프로그램에 등록**:
   - 웹 대시보드의 **[텔레그램 알림 설정]** 탭에 토큰과 Chat ID를 입력하고 **[연결 테스트 및 알림 발송]** 버튼을 눌러 정상 작동을 확인합니다.

대한항공 보너스 항공권의 클래스 코드는 다음과 같습니다:
- **X** : 일반석 보너스 (Economy Award)
- **O** : 프레스티지석 보너스 (Prestige / Business Award)
- **A** : 일등석 보너스 (First Class Award)
- **Z** : 프레스티지석 좌석승급 (Upgrade to Prestige)
- **W** : 프리미엄 일반석 보너스
- **G** : 프리미엄 일반석 좌석승급
