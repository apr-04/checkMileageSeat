# ✈️ 대한항공 마일리지 빈좌석 모니터링 & 웹 대시보드

대한항공(Korean Air SKYPASS)의 마일리지 보너스 항공권(일반석, 프레스티지석, 일등석, 좌석승급)의 잔여 좌석을 정기적으로 스캔하여, **인터넷 웹 대시보드에서 예약 가능한 빈 좌석과 여행지 목록을 한눈에 확인할 수 있는 웹 서비스**입니다.

---

## 🌟 주요 기능

1. **🌍 어디로 갈까? 빈좌석 목적지 탐색기**
   - *"이번 가을/겨울에 프레스티지석(비즈니스) 남아있는 여행지가 어디지?"*
   - 출발지와 원하는 시기(월), 좌석 등급, 지역(일본, 동남아, 유럽, 미주 등)을 고르면 **마일리지 예약이 가능한 목적지와 날짜 목록을 일괄 탐색**하여 카드 형태로 한눈에 보여줍니다.
   - **출국편(서울 ➔ 해외)** 및 **귀국편(해외 ➔ 서울)** 왕복 여정 완벽 지원.

2. **특정 노선 실시간 캘린더 조회**
   - 원하는 노선(예: 인천 ➔ 나리타, 파리 등)의 한 달 치 전체 항공편 잔여 좌석을 고속 조회하여 캘린더 및 일자별 표 형태로 상세 확인.

3. **대한항공 공식 예매 페이지 원클릭 연동**
   - 조회된 좌석의 [예매] 버튼 클릭 시, 해당 출발지/도착지/탑승일자/좌석등급이 미리 적용된 **대한항공 공식 예약 페이지로 직행**합니다.

4. **GitHub Pages를 통한 24시간 무료 웹 대시보드 호스팅**
   - PC를 켜둘 필요 없이 모바일폰이나 PC 웹 브라우저(`https://<아이디>.github.io/<저장소>/`)에서 언제든 최신 좌석 현황을 확인하실 수 있습니다.
   - GitHub Actions가 매시 정각마다 전 세계 노선 좌석 데이터를 자동 갱신합니다.

---

## 🌐 사용 방법

### 1. GitHub Pages 웹 대시보드 접속 (추천)
- 저장소의 GitHub Pages 주소(`https://apr-04.github.io/checkMileageSeat/`)로 접속합니다.
- 상단에서 **출국편** 또는 **귀국편**을 선택하고, 원하는 월과 좌석 클래스를 필터링하여 빈 좌석을 탐색합니다.
- 데이터 갱신이 필요할 때는 상단 **[새로고침]** 버튼을 눌러 GitHub Actions 워크플로우를 즉시 실행할 수 있습니다.

### 2. 내 컴퓨터에서 로컬 실행 (선택 사항)
내 PC에서 직접 실시간으로 웹 서버를 띄워 확인하고 싶을 때:
```bash
# 원클릭 실행 (Windows)
run_web.bat
```
브라우저에서 `http://127.0.0.1:5000`으로 접속하여 즉시 조회할 수 있습니다.

## ⚙️ 자동 데이터 갱신 (GitHub Actions)

- **실행 주기**: 매시 정각 (1시간 주기, WAF 밴 방지)
- **수동 즉시 갱신**: GitHub 저장소의 **[Actions]** 탭 ➔ **`KAL Award Seat Web Dataset Builder`** ➔ **[Run workflow]** 클릭
- **안전 장치**: 스크래핑 실패나 세션 오류로 인해 좌석 데이터가 0건으로 수집될 경우, 기존 정상 데이터를 절대 덮어쓰지 않고 보호하도록 안전 가드가 적용되어 있습니다.
