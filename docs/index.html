휴가 시기에 마일리지 좌석 남아있는 여행지 찾기

원하는 여행 월과 좌석 등급을 선택하시면, 대한항공 주요 취항지 중 현재 마일리지 예약이 가능한 목적지와 날짜 목록을 즉시 필터링하여 보여드립니다.

여정 방향:
현재 [서울 ➔ 해외] 출국편 좌석을 조회 중입니다.
포함할 좌석 등급:

특정 노선 상세 일자별 좌석 조회

원하는 출발지/도착지 및 탑승월을 선택하면 해당 노선의 모든 항공편과 마일리지 잔여 좌석을 확인할 수 있습니다.

인기 노선 바로보기:

탑승일자 편명 출발시각 좌석 클래스 예약 가능 여부 예매

GitHub Actions로 24시간 무료 텔레그램 알림 받기

내 컴퓨터를 켜두지 않아도, GitHub가 30분마다 자동으로 대한항공 좌석을 확인하고 취소표가 나오면 텔레그램으로 알려줍니다.

STEP 1

텔레그램 봇 토큰 발급

1. 텔레그램에서 @BotFather 검색 후 대화 시작
2. /newbot 입력 후 봇 생성
3. 발급된 HTTP API 토큰 복사
4. @userinfobot 에게 대화하여 내 Chat ID 숫자 확인
5. 생성한 봇에게 꼭 /start 메시지 1회 전송!

STEP 2

GitHub Secrets 등록

1. 내 GitHub 저장소의 Settings ➔ Secrets and variables ➔ Actions 이동
2. New repository secret 클릭 후 2개 등록:
• TELEGRAM_BOT_TOKEN : 내 봇 토큰
• TELEGRAM_CHAT_ID : 내 Chat ID

STEP 3

자동 모니터링 활성화

1. 저장소의 Actions 탭으로 이동
2. KAL Award Seat Periodic Monitor 확인
3. 이후 30분마다 GitHub가 알아서 좌석을 확인하고 취소표 발생 시 텔레그램으로 알림을 보냅니다!

좌석 데이터 갱신 안내

최신 마일리지 좌석 데이터를 갱신하는 2가지 방법입니다.

자동 갱신 주기: 매 30분마다 자동 실행

수동으로 새로고침하지 않아도 GitHub Actions가 매 30분마다 대한항공 전체 노선을 자동 검사하여 웹사이트 데이터를 갱신하고, 새로운 빈 좌석 발견 시 텔레그램으로 알림을 보냅니다.

방법 1 • 추천 (토큰 불필요) 소요 시간: 3초

GitHub 웹에서 [Run workflow] 원클릭 실행

GitHub에 로그인되어 있으시면, 별도의 복잡한 Personal Access Token 발급 없이 아래 버튼을 누른 후 [Run workflow] 파란색 버튼만 클릭하시면 즉시 좌석 조회가 시작됩니다!

GitHub Actions 실행 페이지로 바로가기 ➔
방법 2 • 내 컴퓨터에서 실시간 조회 (토큰 불필요)

프로젝트 폴더의 run_web.bat을 실행하시면 내 컴퓨터에서 직접 대한항공 API를 실시간 조회하므로 대기 시간 없이 즉시 최신 결과를 확인하실 수 있습니다.
