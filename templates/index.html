텔레그램 알림 연동

텔레그램 봇 1분 생성 안내

  1. 텔레그램 앱에서 @BotFather 검색 후 대화 시작
  2. /newbot 입력 후 봇 이름 및 아이디 지정
  3. 발급되는 HTTP API 토큰을 위 입력창에 복사
  4. 내가 만든 봇에게 /start 메시지 1회 전송
  5. 내 Chat ID는 텔레그램에서 @userinfobot 검색 후 대화를 걸면 즉시 확인 가능!
